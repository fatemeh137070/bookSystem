نمونه کامل در Postman

    می‌توانید یک Collection جدید بسازید به نام “Books API”.

    داخل آن یک Request به نام “Create Book” با توضیحات زیر:

        Method: POST

        URL: http://localhost:9090/api/books

        Headers: Content-Type: application/json
        //{
        
            "title": "رباعیات خیام",
            "authorId": 1,
            "categoryId": 1,
            "isbn": "978-600-112-345-6"
          }
//

        Body (raw JSON، مثال داده‌شده).

    یک Request دیگر با نام “List All Books”:

        Method: GET

        URL: http://localhost:9090/api/books

        Headers: (نیازی نیست)

        Body: —

    هر بار که Server را Restart می‌کنید، مطمئن شوید رکوردهای Author/Category را در H2 Console مجدداً درج کرده‌اید (چون دیتابیس در حافظه است و با Stop/Start پاک می‌شود).

وارد لینک دیتابیس اچ 2 می شی
    http://localhost:9090/h2-console

     JDBC URL: jdbc:h2:mem:librarydb

۱. تست ساخت کتاب (POST)

    URL: POST http://localhost:9090/api/books

    Headers:

        Content-Type: application/json

        {
          "title": "کتاب نمونه",
          "authorId": 1,
          "categoryId": 2
        }


 -------   --------------------- --------------   ----------------------------------


۲. گرفتن همه کتاب‌ها (GET)

    URL: GET http://localhost:8080/books

    Headers: لازم نیست چیزی اضافه کنی.

۳. گرفتن کتاب‌های یک نویسنده خاص (GET)

    URL:
    GET http://localhost:9090/books/author/{authorId}
    مثلا:
    GET http://localhost:9090/api/books/author/1

۴. گرفتن کتاب‌های یک دسته‌بندی خاص (GET)

    URL:
    GET http://localhost:8080/books/category/{categoryId}
    مثلا:
    GET http://localhost:9090/api/books/category/1
